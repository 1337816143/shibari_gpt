# Image 2 统一人物参考图提示词记录

> 当前仓库只记录生成规范，尚未提交任何自动生成的人物图或转换结果。输出必须由人工确认成年身份、比例一致性和服装适用性后才能进入模型制作。

## 统一角色主提示词

成年女性训练模特，年龄明确为 25–35 岁，身体比例自然，非名人，非真实特定人物，面部中性平静，发型固定为低马尾，穿深灰蓝色专业贴身运动训练服，服装完整不透明，肩、肘、腕、髋、膝、踝等人体标志清楚可见，赤足，白灰色无缝摄影棚背景，均匀柔光，正交感较强的中长焦镜头，真实人体结构，高分辨率，非色情化，非戏剧化姿势，用于教育与 3D 建模参考。

## 多视图约束

分别生成：正面、背面、左侧、右侧、左右四分之三。保持同一人物、相同身体比例、相同服装、相同发型、相同光照、相同相机高度和近似焦距。标准 A-pose 或自然中立站姿，不改变体重、肌肉量或面部。

## 教学姿势约束

中立站立，双脚完全支撑，右前臂轻微前伸，肩部自然下沉，肘关节轻度屈曲，腕部中立，手指放松。不得出现承重、吊缚、极限关节角度或戏剧化表情。

## 负面约束

未成年人、年轻化面容、裸露、透明服装、色情化动作、夸张胸臀比例、极端腰臀比、高跟鞋、遮挡关节、长发遮挡背部、鱼眼畸变、手指缺失、四肢变形、背面结构缺失、不同视图身份变化、不同服装、不同相机高度。
