# 3D 人物资产验收门槛

本清单用于决定一个人物资产是否可以从 `technical-review` 进入课程审核。通过浏览器成功显示，不等于可以作为绳艺教学模型。

## 1. 来源与许可

- 必须保留原始来源页面、许可证页面、作者或机构署名。
- 禁止使用来源不明、许可证不允许再分发、仅限个人用途或无法确认授权链的模型。
- 远程模型必须显式设置 `allowRemote: true`；正式发布优先使用仓库内受控资产。
- 若资产经过重拓扑、换装、贴图重绘或骨骼修改，应记录修改者、日期、软件和导出版本。
- 文件进入仓库后记录 SHA-256，替换文件必须更新版本和校验值。

## 2. 人物与视觉要求

- 明确为成年人，外观中性，不采用未成年人特征。
- 全身完整着装，不裸露，不使用色情化姿势、服装或镜头语言。
- 身体比例、关节位置、手指和足部应足以支持教学观察。
- 服装应贴合但不误导人体结构；需要观察的解剖标志不能被夸张褶皱遮挡。
- 正面、背面、左右侧和顶部视角均不得出现穿模、翻面或明显破损。

## 3. 几何与材质

- 单位、朝向和原点统一；站姿脚底应落在场景地面。
- 网格不得存在大面积非流形结构、重复面、破面或错误法线。
- 材质数量、纹理尺寸和透明材质数量应受控。
- 不依赖未声明的外部纹理；正式 GLB 应能在断网环境完整加载。
- 半透明材质应检查排序、深度写入和移动端兼容性。

## 4. 骨骼与姿势

- 骨骼层级、命名和绑定姿势必须记录。
- 肩、肘、腕、髋、膝、踝和手指的旋转中心应接近实际关节。
- 权重不得在弯曲时产生明显塌陷、拉丝或身体部位粘连。
- 每个课程姿势必须在模型上单独验收，不能只验证 T Pose 或 A Pose。
- 课程禁止的姿势漂移，应能通过骨骼约束或人工校验发现。

## 5. 绳路教学适配

- 模型坐标与课程绳路坐标必须使用同一基准。
- 接触点、安全检查点和风险区必须与可见人体位置一致。
- 绳索不得明显穿入身体，也不能因模型缩放而悬空。
- 镜像模式、推荐视角和局部特写必须重新检查。
- 更换人物模型后，所有绳路与姿势审核自动失效，必须重新确认。

## 6. 性能预算

建议的首版预算，而非最终硬性标准：

- 单人物 GLB 下载体积不超过 8 MB；移动端优先不超过 5 MB。
- 纹理以 1K–2K 为主，只有明确需要时使用 4K。
- 建议提供桌面与移动端 LOD，或至少提供简化网格。
- 首次加载失败、超时或 WebGL 不可用时，必须显示程序化模型或二维图，不得出现空白教学区域。

## 7. 审核状态

- `placeholder`：仅工程占位，不允许作为正式课程证据。
- `technical-review`：许可和加载链路可验证，但尚未完成姿势、绳路和安全审核。
- `approved`：仅表示模型资产通过技术与视觉验收，不等于课程内容已通过安全审核。

## 外部 QA 资产

仓库登记了 Khronos glTF Sample Assets 的 `RiggedFigure`，仅用于验证 GLB、皮肤与动画加载链路。该资产由 Cesium 提供，采用 CC BY 4.0；它不是本项目要求的成年女性正式教学人物，不会作为默认课程模型或最终视觉方案。
