# Phase 4：受控人物资产管线

## 目标

本阶段将“浏览器能显示 GLB”升级为可审计、可失败、可回退的资产链路。它仍不表示最终写实教学人物已经完成。

## 浏览器加载顺序

1. 课程 Schema 明确声明资产来源、许可证、完整着装成年人呈现、审核状态、体积预算和超时。
2. 本地或明确授权的远程地址通过 `fetch` 下载到内存。
3. 下载前检查 `Content-Length`，下载后再次检查实际字节数。
4. 资产登记 SHA-256 时，使用 Web Crypto 对完整 ArrayBuffer 进行强校验。
5. 校验通过后创建临时 Blob URL，再交给 glTFLoader 解析。
6. 使用 SkeletonUtils 克隆骨骼场景，每个实例单独克隆材质。
7. 显示网格、蒙皮网格、骨骼、三角面、材质、下载体积和包围盒尺寸诊断。
8. 下载、超时、完整性或解析失败时只替换为程序化人物；绳路和安全叠加层继续显示。
9. WebGL 整体失败时再降级到二维分步图。

## 技术 QA 资产

Khronos glTF Sample Assets 的 RiggedFigure 仅验证：

- 本地 GLB 路径；
- CC BY 4.0 归属记录；
- 骨骼和蒙皮解析；
- SHA-256；
- 模型级错误回退；
- 运行时诊断。

它不是最终成年女性教学人物，也不会自动使课程进入审核状态。

## 写实人物候选管线

优先尝试 MakeHuman / MPFB，因为核心资产及导出模型为 CC0，且官方脚本 API 已覆盖：

- 创建成年人女性基础网格；
- 设置 GAMEENGINE 皮肤材质；
- 添加 game-engine rig；
- 添加眼睛、眉毛、睫毛、头发和完整服装；
- 烘焙修改器并移除辅助几何；
- 从 Blender 导出 GLB。

候选模型仍必须经过 `asset-acceptance-checklist.md`，尤其是年龄呈现、完整着装、肩肘腕权重、课程姿势、绳路接触、移动端性能和许可证链。

## 不自动通过的事项

- “来自 CC0 生成器”不等于模型质量合格；
- “带骨骼”不等于关节旋转中心与权重正确；
- “没有报错”不等于绳路与人体位置一致；
- “模型资产 approved”不等于课程 safety-review 或 approved。
