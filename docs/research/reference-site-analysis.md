# 参考网站分析报告

> 调研日期：2026-08-02。用途仅限产品结构、教学交互和安全信息架构研究，不复制付费课程、图片、视频、模型或具体受版权保护内容。

## 核心结论

1. 中文站点普遍具备“基础/简单/中级/高级”分类、资源库和会员体系，但课程质量、来源、版权状态与安全审核标识不统一。
2. Animated Knots 的优势是分类、搜索、用途说明、逐帧动画、镜像和低学习成本。
3. Knots 3D 的优势是 360°旋转、动画拖动、速度控制、离线性能和高辨识度绳材质。
4. 人体绳艺产品不能照搬普通绳结产品。必须额外建立人物姿势、接触区域、受力方向、风险区域、检查点和解除顺序的数据层。
5. KSBADA 更接近视频/审美内容聚合，不应作为专业教学产品的信息架构或视觉定位。

## 单节课程页面建议

页面固定分为五层：

1. **课程门槛**：适用范围、不适用情况、前置技能、材料、审核状态。
2. **3D 练习区**：人物、绳索、风险层、相机预设、镜像和透明度。
3. **步骤播放器**：上一步、下一步、播放、暂停、循环、速度和任意跳转。
4. **步骤说明**：目标、绳头方向、操作手、松紧、检查、常见错误和解除。
5. **审核与来源**：姿势来源、绳路来源、差异记录、审核人和版本。

## 不应采用的设计

- 以内容数量代替审核质量。
- 把安全信息只放在免责声明或独立文章。
- 只显示最终效果，不显示中间绳路和解除路径。
- 自动播放但不能暂停、拖动、镜像或改变视角。
- 允许用户拖动人体关节改变已审核姿势。
- 使用来源不明、无许可证或无法证明成年身份的模型。
- 在移动端让文字面板遮挡当前操作区域。
- 高风险课程与初学课程混排、无前置门槛。
