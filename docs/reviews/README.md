# 独立审核工作流

课程不能由开发者自行把状态改成 `approved`。正式发布需要三类相互独立、绑定版本的审核记录。

## 必需角色

### 1. 绳艺技法审核 `rope-technique`

审核范围至少包括：

- 人物姿势与支撑状态；
- 每一步绳路、活动绳头和张力方向；
- 接触位置、平行绳股和常见错误；
- 检查顺序、停止条件和快速解除；
- 镜像、推荐视角和步骤文字是否与 3D 一致。

记录必须绑定 `courseVersion`。

### 2. 医学/人体结构审核 `medical-anatomy`

审核范围至少包括：

- 接触点、神经与循环相关风险区域；
- 麻木、刺痛、灼痛、无力等停止条件；
- 姿势对肩、肘、腕、髋、膝和呼吸的影响；
- 检查频率、解除要求和风险措辞；
- 是否存在会被误解为诊断或绝对安全保证的表述。

记录必须绑定 `courseVersion`。

### 3. 模型技术审核 `model-technical`

审核范围至少包括：

- 来源、许可证、成年人呈现和完整着装；
- GLB 哈希、几何、材质、纹理与性能预算；
- 骨骼层级、关节中心、蒙皮权重和课程姿势；
- `boneMap`、landmark、绳路和接触点的空间一致性；
- 桌面和移动端真机表现。

记录必须绑定 `modelVersion`。

## 状态规则

- `requested`：已邀请审核，尚未开始；
- `in-review`：正在审核；
- `changes-required`：存在必须修改的问题；
- `approved`：该角色对指定版本批准；
- `rejected`：该版本不适合继续发布。

课程或模型版本变化后，旧记录仍可保留为历史证据，但不再满足当前发布门禁。

## 证据保存

每条审核记录应保留：

- 审核者真实姓名或可核验身份；
- 审核角色；
- 审核范围；
- 被审核版本；
- UTC 时间；
- 结论与修改意见；
- 可选的会议纪要、签字表或问题单地址。

模板见 `review-record-template.json`。模板中的示例不得直接作为真实批准记录提交。
