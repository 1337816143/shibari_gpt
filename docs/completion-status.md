# 项目完成状态

本文区分四种状态：工程实现、技术候选资产、公开演示部署、正式教学发布。四者不能混为一谈。

## 1. 工程实现：完成

### 网站与学习流程

- 响应式首页、课程库、搜索和分类；
- 安全确认前不下载 3D 引擎或人物 GLB；
- 360° 视角、相机预设、镜像和画质控制；
- 播放、暂停、重播、时间轴、速度、循环和步骤跳转；
- 步骤目标、说明、张力、错误、检查、解除和完成清单；
- 本地收藏、完成记录和继续学习；
- 术语表、研究状态和审核透明度；
- WebGL 或人物加载失败时的程序化模型和二维降级。

### 3D 教学引擎

- 程序化成年人占位模型；
- 多候选人物选择器；
- GLB 加载、体积预算、超时和 SHA-256；
- 骨骼安全克隆、独立材质和动画选择；
- 网格、蒙皮网格、骨骼、三角面、材质和尺寸诊断；
- Catmull-Rom 绳路渐进显示；
- 操作手、方向箭头、接触点、风险点和错误路径；
- 世界坐标和语义骨骼局部坐标；
- `boneMap` 与缺失骨骼显式错误。

### 数据、资产与发布治理

- Zod 课程、姿势、模型、步骤和审核 Schema；
- 本地模型资产清单和候选目录元数据；
- 来源、许可证、哈希、预览图和 GLB 容器静态校验；
- `boneMap` 对实际 GLB 节点的静态验证；
- 版本绑定的模型、绳艺和医学审核；
- 课程批准状态不可绕过的运行时门禁；
- 模型验收清单和外部审核模板；
- 锁定依赖、浏览器测试、体积预算和 Pages 自动发布；
- Blender 4.5 LTS + MPFB + CC0 MakeHuman 资产的可复现候选目录生成与自动写回。

## 2. 技术候选人物：完成并可选择

仓库和页面保留以下全部选项：

1. MPFB 休闲装移动版：约 11.6 MiB，最大贴图 1024，默认选中；
2. MPFB 休闲装原始质量：约 24.2 MiB，最大贴图 4096；
3. MPFB 运动装原始质量：约 17.7 MiB，最大贴图 2048，腹部露出并明确标注；
4. Khronos RiggedFigure 技术 QA；
5. 项目程序化训练人台。

三套 MPFB 候选均包含：

- 成年女性参数和中性 A Pose；
- 8 个网格、1 个蒙皮骨架、53 个关节；
- game-engine rig 和 20 项稳定语义骨骼映射；
- 正、背、左、右四视图；
- CC0 来源与许可证；
- SHA-256；
- 候选生成报告和独立 GLB 审计。

运动装未被删除。它作为 `neutral-sportswear-midriff` 技术候选保留，但正式课程批准 Schema 仍要求 `neutral-fully-clothed`，因此“允许用户比较”不会绕过正式发布规则。

## 3. 公开演示部署：工程链路完成

公开地址：

`https://1337816143.github.io/shibari_gpt/`

发布链路为：

1. 开发分支运行 lint、严格类型检查、模型供应链校验、单元测试、生产构建和 Playwright E2E；
2. 只有 CI 成功后，默认分支上的生产 Pages 工作流才会启动；
3. 生产工作流使用该次 CI 的精确 `head_sha` 构建；
4. 构建产物写入 `deployment.json`，记录实际部署源提交；
5. 部署后从公网校验提交指纹、首页、404、JavaScript、CSS 和模型资产；
6. 公网模型必须与仓库 SHA-256 清单一致。

应用代码仍位于 Draft PR 的开发分支，未合并到 `main`。

## 4. 正式课程：外部独立审核未完成

技术候选已经存在，但还不能诚实地称为正式教学完成。仍需真实人员完成：

- 候选人物在课程规定姿势下的肩、肘、腕、髋、膝、踝权重验收；
- 每个步骤的绳路贴合、穿模、接触点和风险区对齐；
- 专业绳师逐步校验绳路与解除顺序；
- 医学/人体结构审核停止条件、受压位置和安全文字；
- 模型技术审核最终选中的候选和版本；
- 更多真实移动设备的内存、发热和长时间运行测试。

这些审核不能由开发者或自动化系统伪造。审核记录必须绑定当前 `courseVersion` 或 `modelVersion`；版本变化后，旧批准自动失效。

## 5. 当前完成定义

当前已达到：

- 工程平台完成；
- 三套 MPFB 技术候选完成并可在页面选择；
- 原始质量和移动优化交付层级都被保留；
- 发布和模型供应链可重复审计；
- 外部专家审核尚未完成，且页面不会将其伪装为完成。

下一阶段不再需要从零寻找人物模型，而是由项目所有者在现有候选中选择主模型，再围绕该模型进行姿势、权重、绳路和专业安全审核。
